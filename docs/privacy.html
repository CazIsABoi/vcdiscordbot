Privacy Policy

Last updated: 2026-09-29

This Privacy Policy explains what data the VCDiscordBot Discord bot (the "Bot") collects and how it's used.

1. What the Bot collects

The Bot stores only the following, per server it's added to:

  • The Discord server (guild) ID;
  • The channel ID configured as the "join to create" channel, and its category ID;
  • The channel ID and owning member's Discord user ID for each active temporary voice channel, so ownership commands (lock, kick, transfer, etc.) work correctly.
  • For each GitHub repository linked to a thread with /github link: the repository's name, the thread ID, the Discord user ID of whoever linked it, the ID of the Discord webhook created for it, and when a commit was last posted.

The Bot does not read, log, or store message content — it does not request Discord's message content permission. It does not record voice audio; it only manages channel creation, deletion, and permissions.

When you link a GitHub repository, you sign in to GitHub and grant the Bot temporary access. The Bot uses that access once to add a commit webhook to the repository, then revokes or discards it. Your GitHub access token is never stored or logged. Commit notifications are sent by GitHub directly to Discord; they do not pass through the Bot.

2. Use of AI

The Bot's code was developed with the help of an AI coding assistant (Claude Code). The Bot itself does not run on or call any AI or machine-learning model at runtime — it is rule-based automation that creates and deletes voice channels and enforces permissions. No data described in this policy is sent to an AI model or used to train one.

3. How this data is used

This data is used exclusively to operate the temporary voice channel feature: knowing which channel to watch for new joins, and which member owns which temporary channel so that owner-only commands can be enforced, and knowing which GitHub repositories post to which threads so links can be listed, removed, and cleaned up when inactive.

4. Data retention and deletion

  • A temporary channel's record is deleted automatically as soon as the channel itself is deleted (i.e. once it's empty).
  • A server's configuration (join channel, category) is deleted when an administrator runs /tempvc-setup disable, or automatically when the Bot is removed from the server.
  • A GitHub link is deleted when someone runs /github unlink, when its thread is deleted, after 37 days without commits (with a warning posted after 30), or when the Bot is removed from the server.

5. Data sharing

Data is not sold, shared, or disclosed to any third party. It is stored only in the Bot's own database and is accessible only to whoever operates the Bot's hosting. The only exception is GitHub linking: at your request, the Bot gives GitHub the address of the Discord webhook created for your thread so GitHub can post commits to it.

6. Your rights

Since the only data stored is Discord IDs needed for the Bot's core feature, the most direct way to remove your server's data is to remove the Bot from your server (see Terms of Service, Section 6), or to have a server administrator run /tempvc-setup disable. You can also request deletion by contacting us as described below.

7. Changes to this policy

This policy may be updated from time to time; changes will be posted at this URL with an updated "Last updated" date.

8. Contact

Questions about this policy, or data deletion requests, can be raised via cazpex@gmail.com or GitHub Issues on the project repository.
