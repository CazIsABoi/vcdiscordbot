VCDiscordBot

A temporary voice channel bot for Discord.

Join the configured "create voice channel" in a server and get your own temporary voice channel, which is deleted automatically once everyone leaves. See the source code and setup instructions on GitHub.

AI disclosure: This bot's code was built with the help of an AI coding assistant (Claude Code). The bot itself does not use AI — it's plain rule-based automation that creates and deletes voice channels and does not read message content or process user data with any AI or machine learning model.
